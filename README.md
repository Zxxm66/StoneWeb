# 🛍️ StoneWeb - Web Store Catalog

Веб-каталог интернет-магазина одежды **Stone** с минималистичным дизайном в стиле Balenciaga для Telegram WebApp.

> Это веб-версия магазина одежды Stone, которая открывается внутри Telegram через кнопку WebApp в боте [Stone](https://github.com/Zxxm66/Stone). Позволяет пользователям просматривать каталог, выбирать товары и оформлять заказы прямо в браузере Telegram.

## 📸 Превью

Современный веб-интерфейс магазина с фокусом на минимализм, типографику и user experience.

## 🎯 Возможности

### Для покупателей:
- 👕 **Каталог товаров** - стильная витрина с одеждой
- 🔍 **Детальные карточки** - фото, описание, размеры, цены
- 📏 **Выбор размеров** - удобный выбор размерной сетки (S, M, L, XL)
- 🛒 **Корзина покупок** - добавление товаров и оформление заказа
- 💳 **Оформление заказа** - интеграция с оплатой и доставкой
- 📱 **Telegram WebApp** - работает внутри Telegram без открытия браузера
- 🎭 **Balenciaga-style** - минималистичный премиум дизайн
- ⚡ **Быстрая загрузка** - оптимизированная производительность

## 🛠️ Технологии

**Backend:**
- Python 3.x
- aiohttp - асинхронный веб-фреймворк
- aiohttp_jinja2 - шаблонизация
- SQLite - база данных
- python-dotenv - управление конфигурацией

**Frontend:**
- HTML5/CSS3
- JavaScript (Vanilla)
- Telegram WebApp API - интеграция с Telegram
- Адаптивная верстка
- Современные CSS-анимации
- Balenciaga-inspired дизайн

**Интеграция:**
- Telegram Bot API
- Telegram WebApp для встраивания в бота

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Zxxm66/StoneWeb.git
cd StoneWeb
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации
Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
STORE_HOST=0.0.0.0
STORE_PORT=8000
DB_PATH=data/shop.db
```

### 4. Запуск приложения
```bash
python StoneWeb.py
```

Приложение будет доступно по адресу: `http://localhost:8000`

## 💾 База данных

Проект использует SQLite для хранения данных:
- **Товары** - каталог с описаниями, ценами, размерами
- **Заказы** - история заказов и их статусы

База данных создается автоматически при первом запуске.

## 🔗 Интеграция с Telegram Bot

StoneWeb - это веб-интерфейс магазина для Telegram-бота [Stone](https://github.com/Zxxm66/Stone):
- Открывается через кнопку WebApp в боте
- Telegram API для авторизации пользователей
- Единая база данных с ботом
- Синхронизация корзины между ботом и веб-версией
- Уведомления о заказах через бота

**Как работает:**
1. Пользователь открывает бота Stone в Telegram
2. Нажимает кнопку "🛍️ Открыть магазин" или "🌐 Web-версия"
3. Открывается StoneWeb внутри Telegram (Telegram WebApp)
4. Пользователь выбирает товары, добавляет в корзину, оформляет заказ
5. Заказ попадает в систему и обрабатывается через бота
